# COS30017 Software Development for Mobile Devices 移动设备软件开发 - 课程大纲

---

## 课程概述 / Course Overview
本课程旨在介绍面向移动设备的软件开发与设计，强调**实践操作与动手编程**（Outcome Unit / Hands-on Coding）。课程将引导学生掌握移动平台开发的特色与挑战，并结合面向对象编程（OOP）概念与现代 AI 工具完成移动应用程序的构建。

This unit introduces software development and design for mobile devices, emphasizing **hands-on coding and practical outcome-based learning**. It guides students to master the unique characteristics and challenges of mobile platforms, combining Object-Oriented Programming (OOP) concepts and modern AI tools to build mobile applications.

---

## 1. 核心教学内容 / Core Teaching Contents

* **移动端与传统环境的区别 / Differences Between Mobile and Desktop/Web Environments**
  * 系统讲解移动设备系统与传统个人电脑（PC）或互联网环境在开发、架构与用户体验上的关键差异。
  * Explains the key differences in development, architecture, and user experience between mobile systems and traditional desktop (PC) or web environments.

* **硬件约束下的应用设计 / Application Design Under Hardware Restrictions**
  * 深入探讨如何在受限的移动硬件环境（如较小的屏幕尺寸、有限的内存容量和 CPU 处理能力）下设计高效且流畅的应用。
  * Explores how to design effective mobile applications while managing hardware constraints such as screen size, memory limitations, and processor capability.

* **图形应用构建与排错调试 / Building, Testing, and Debugging Graphical Applications**
  * 学习使用移动开发者工具包（Developers' Toolkit）中自带的标准 SDK 和 API 库进行图形界面应用的搭建、自动化测试与排错。
  * Teaches building, testing, and debugging graphical mobile applications using standard libraries bundled with the developer's toolkit.

* **Android Studio & Kotlin 开发 / Android Studio & Kotlin Development**
  * 基于 Android Studio 开发环境，应用面向对象编程（OOP）思想，掌握 Kotlin 编程语言并编写实际移动软件项目。
  * Uses the Android Studio IDE and Object-Oriented Programming (OOP) principles to learn Kotlin programming for real-world mobile software projects.

* **生成式 AI 协同开发规范 / Responsible Generative AI Co-pilot Usage**
  * 教授如何将生成式 AI（如 ChatGPT、Gemini、Claude AI 等）作为编程“副驾驶”（Co-pilot），同时掌握相应的学术规范（包含提示词附录与代码注释引用）。
  * Covers using Generative AI tools (e.g., ChatGPT, Gemini, Claude AI) as a development co-pilot, alongside proper academic acknowledgement (prompt/output appendices and code comment citations).

## 2. 学习收获与目标 / Learning Outcomes & Skills Gained

* **移动开发特性理解与设计应用 / Understanding and Applying Mobile Characteristics**
  * 能够准确解释移动系统的特殊性，并灵活应用于移动应用的设计与架构中。
  * Explain the unique characteristics of mobile systems and apply this knowledge effectively to mobile application design and architecture.

* **针对硬件限制的优化设计能力 / Optimized Application Design for Hardware Constraints**
  * 能够综合考虑屏幕、内存及 CPU 性能等设备硬件限制，设计出高品质的移动应用。
  * Design high-quality applications by taking into account hardware-imposed restrictions like display, memory, and processing power.

* **全流程移动应用工程技能 / Full-Lifecycle Mobile App Engineering Skills**
  * 熟练运用标准开发库完成移动图形应用从零构建、功能测试到排错调试的全套工程实践。
  * Build, test, and debug graphical mobile applications using standard developer tools and libraries.

* **Kotlin & OOP 面向对象实战能力 / Practical Skill in Kotlin & OOP**
  * 深入理解并运用面向对象概念，熟练使用 Kotlin 语言实现应用业务逻辑。
  * Apply Object-Oriented concepts and Kotlin programming language fluently in mobile software development.

* **自主学习与技术调研能力 / Independent Research & Self-Directed Learning**
  * 培养在面对新软件工具或技术挑战时独立调研、自学并解决难题的能力。
  * Develop the capacity for independent reading, technical research, and self-directed problem-solving when encountering new technologies.

* **规范使用 AI 辅助开发的素养 / Responsible AI-Assisted Development**
  * 掌握在软件开发中合规、规范使用 AI 辅助代码生成的流程与引用规则。
  * Master the responsible usage, documentation, and citation of Generative AI tools in software engineering workflows.

## 3. 实践与实验室环节 / Practical & Lab Syllabus

* **开发环境配置与入门 / Getting Started with Android Studio**
  * 掌握 Android Studio IDE 环境安装、模拟器配置与基础项目搭建。
  * Setup Android Studio, configure emulators, and initialize basic Android projects.

* **代码实践与逻辑实现 / Coding Practice & Logic Implementation**
  * 配合指导视频完成基础代码编写练习，掌握移动端核心业务逻辑。
  * Practice coding with instructional videos to implement core mobile application logic.

* **实验示范与代码演示 / Lab Demonstrations & Assignment Sign-off**
  * 观摩实验室示例代码，独立完成作业，并在实验室与导师进行现场代码演示与答辩（Sign-off）。
  * Review lab demo videos, complete individual assignments, and undergo physical/online in-lab code demonstrations and sign-offs with instructors.
